# MOSAIC 3D Expense Tracker - Progress & Build Log

## Project Objective
Build MOSAIC — an ultra-premium, dark futuristic 3D expense tracking web app matching the reference design (image.png) and PRD.md.
Follow "Ponytail" rules (no over-engineering, YAGNI, lean architecture, direct Three.js canvas without heavy wrapper bloat, clean modular structure, zero generic vibe-coded templates).

---

## Current Architecture Plan
- **Framework**: Vite + React + TypeScript (fast, lightweight, highly responsive)
- **Styling**: Tailored Modern CSS / Glassmorphism Design System matching reference image (deep navy `#080c14`, translucent glass cards, neon teal/mint `#00f5a0` & `#05d59e`, electric orange `#ff7b25`, cobalt `#2563eb`, vivid category accents).
- **3D Visualization**: Direct Three.js with Raycasting (interactive floating category spheres/shapes: Orange sphere for Food, Blue cube for Transport, Green sphere for Shopping, Yellow/Lime ring/torus for Bills, Purple sphere for Other, orbit rings, lighting, particle dust, interactive tooltips/clicks).
- **Charts**: Custom ultra-crisp interactive SVG charts (Donut category breakdown with center readout & 6-month dual-bar + trendline chart) avoiding heavy chart library quirks and perfectly matching the visual design.
- **State & Storage**: Reactive local store with localStorage persistence, initial seed data matching the mockup (`₹12,450` spent, `₹20,000` budget, categories, October 2026 transactions).
- **Views & Modals**:
  - Main Dashboard (Overview): Top greeting, 4 Stat Cards with live sparklines & progress, 3D Orbit, Donut Breakdown, Spending Trend, Recent Transactions.
  - Add Expense Modal: Clean modal with amount, description, category, date, payment method, validation.
  - Transactions View: Full searchable, filterable transaction table with edit/delete.
  - Budgets View: Adjust monthly budget, breakdown by category target.
  - Category Filter: Clicking any 3D category or chart item filters dashboard & transactions.
